# Example Job Posting Screenshot

## What to Screenshot

Here's what a good job posting screenshot should include:

```
┌────────────────────────────────────────────────┐
│  [Company Logo]                    [Apply Now] │
│                                                 │
│  Software Engineering Intern                    │
│  Google · Mountain View, CA                     │
│  💰 $50/hour                                    │
│                                                 │
│  About the Role:                                │
│  As a Software Engineering Intern at Google,    │
│  you'll work on cutting-edge technologies...    │
│                                                 │
│  Responsibilities:                              │
│  • Write and test code                          │
│  • Participate in design reviews                │
│  • Work with mentors                            │
│                                                 │
│  Qualifications:                                │
│  • Currently pursuing CS degree                 │
│  • Strong programming skills                    │
│  • Experience with Python, Java, or C++         │
│                                                 │
│  Apply at: careers.google.com/jobs/123          │
└────────────────────────────────────────────────┘
```

## Key Elements to Capture

✅ **Company Name** - Clear and visible
✅ **Job Title** - Full title
✅ **Location** - City, state, remote status
✅ **Compensation** - Salary, hourly rate, or range
✅ **Job Description** - As much detail as visible
✅ **Qualifications** - Requirements and preferences
✅ **Application Link** - URL or email address
✅ **Application Instructions** - Email subject, etc.

## Good Sources for Screenshots

1. **LinkedIn Jobs**
   - Shows company, title, description, apply link
   - Often has salary info
   - Clear application method

2. **Company Career Pages**
   - Official descriptions (most detailed)
   - Direct application links
   - May have full job details

3. **Greenhouse / Lever Boards**
   - Tech company standard
   - Well-formatted
   - All details in one place

4. **Indeed Listings**
   - Aggregated from multiple sources
   - Usually has company info
   - Apply button visible

5. **University Job Boards**
   - Intern/new grad focused
   - Often has deadline info
   - May include contact email

## Screenshot Tips

1. **Full Page**: Capture the entire job posting if possible
2. **Zoom Out**: Make sure company name and title are visible
3. **Include Apply Button**: Capture the application method
4. **Clear Text**: Make sure text is readable (not blurry)
5. **PNG/JPG**: Any common image format works

## What the System Extracts

From your screenshot, the AI will extract:

```json
{
  "company": "Google",
  "job_title": "Software Engineering Intern",
  "role_type": "Intern",
  "compensation": "$50/hour",
  "job_description": "Full detailed description...",
  "application_link": "https://careers.google.com/jobs/123",
  "application_method": "Website URL",
  "email_subject": "N/A"
}
```

Then it will:
1. Enhance the description if needed
2. Add to your Excel sheet
3. Transform your resume for this specific job
4. Embed the resume download link
